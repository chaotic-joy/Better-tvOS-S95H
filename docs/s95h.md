# Samsung S95H (77") plan

Fork of [CleanFrame](https://github.com/nthnclrk/CleanFrame) (MIT), adapted for a 2026 Samsung S95H OLED.

## What is and isn't possible

- **You cannot replace the TV's operating system.** Tizen firmware is signed and the bootloader is locked. No supported or safe way exists to flash custom firmware, and trying risks bricking the panel and voiding the warranty.
- **You can install your own launcher app** through Developer Mode, signed with your own Samsung certificates. That is what this repo builds: your apps, a photo and the clock, without Smart Hub's ad rows.
- **Optionally, the remote's Home button can be routed to your launcher.** This uses undocumented native settings, is firmware-specific, and has a recovery risk. Treat it as a separate experiment (`docs/agent-tv-setup-guide.md`, stages 7–8).
- Samsung's own screens (Settings, inputs, its app store) still show Samsung UI.

## Evidence for this model

Nothing has been verified on an S95H yet. The closest reports in `docs/compatibility.md`:

| TV | Result |
| --- | --- |
| QN55S85FAGXPE (2025 OLED, Tizen 9) | Launcher installed and worked; native Home worked with a **locally adapted** firmware guard |
| UN43M70HAFXZX (Tizen 10) | No launcher result supplied |

This TV: **QN77S95HAFXZC** (Canada), firmware **T-RSMHAKUC-0100-1247.5**, on a new 2026 platform (`RSMH`). `sdb capability` confirms **Tizen 10.0 on 32-bit ARMv7**. It also reports `intershell_support:disabled`, which blocks general shell access. That is likely to block the native Home helper too. Connect with the port given explicitly: `sdb connect <TV_IP>:26101`; the bare IP failed on this TV. The native Home helper's guards (`scripts/native-home/run.py`, `Control.cs`) are hard-coded to the reference TV. They will refuse this one until they are reviewed for this exact firmware.

## Cut the ads now (no developer tools)

Do these first. They are reversible, and menu names vary by firmware:

1. **Settings → General & Privacy → Terms & Privacy**: turn off Viewing Information Services, Interest-Based Advertisements and voice-recognition services.
2. **Settings → General & Privacy → Start Screen Option** (or Smart Features): turn off *Autorun Smart Hub*. Turn on *Autorun Last App* if you want it to resume your launcher.
3. Optional: network-level blocking (Pi-hole, NextDNS, or your router's DNS filter) for Samsung ad and telemetry domains. Some block lists break the app store or firmware updates, so allow-list as needed.

## Stages

Each stage is done with you watching the TV. Stop after any stage.

1. **Preview in a browser**: `npm ci && npm run dev:public`, then open <http://localhost:4795/home/>. Customise apps, wallpaper and layout here.
2. **Record the TV**: Settings → Support → About This TV. Note the model code and the full software version, plus the TV's IP from Network Status. Keep these in `.local/` (ignored).
3. **Developer Mode**: Apps → press `1 2 3 4 5` on the remote → On → enter this Mac's IP → restart the TV.
4. **Tools and certificates**: install Tizen Studio with the TV extensions and the Samsung Certificate Extension. Sign in with your Samsung account yourself. Create a certificate profile that includes this TV's DUID.
5. **Identity**: copy `signing.example.json` to `.local/signing.json` and fill in your SDK path, profile and SDK-generated package/app IDs. Never use the upstream `nClrkHome1` identity.
6. **Install and launch**: package, sign and install with `scripts/package.py` / `scripts/tv.py`. Then confirm that the apps on your TV launch from it.
7. **(Optional) Home button** — **not available on this TV.** A read-only probe on 2026-11-10 found the privileged execution route the native-home helper needs is blocked: the plain `0 appinstall` SDK command works, but any shell-metacharacter injection returns `closed` (this TV reports `intershell_support:disabled`). Without that route the Home-routing change can't be applied *or* rolled back, so it's not attempted. Exiting an app returns to Samsung Home. See `scripts/native-home/README.md` for the method; the adapted read-only probe is kept privately at `.local/native-home/run-s95h.py`.

Detailed per-stage instructions and completion checks are in `docs/agent-tv-setup-guide.md`.
